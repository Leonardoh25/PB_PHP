# Meu Futuro Profissional — Leonardo

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript.

## Como visualizar
Abra o arquivo `index.html` em um navegador. Para desenvolvimento, recomenda-se usar a extensão Live Server no VS Code.

## Arquivos
- `index.html`: estrutura e conteúdo do site.
- `style.css`: identidade visual, layout responsivo e animações.
- `script.js`: menu mobile, alternância de tema, animações de entrada e ano automático.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `meu-futuro-profissional`.
2. Envie os arquivos `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço será `https://SEU-USUARIO.github.io/meu-futuro-profissional/`.

## Personalizações incluídas
1. Paleta escura em tons de verde, inspirada na conexão entre tecnologia e Agronomia.
2. Layout responsivo para computador e celular.
3. Alternância entre tema escuro e claro, com preferência salva no navegador.
4. Menu mobile e animações de entrada das seções.
